# HomeCareNursing

訪問看護の業務をシミュレーション・教育・評価で支えるAIエージェントの計画書です。

## 1. 目的・対象ユーザー・利用シーン
- 目的: 訪問看護の判断力/コミュニケーション/記録力の向上、標準化された評価支援
- 対象ユーザー: 看護学生、新人・中途訪問看護師、指導者/教育担当
- 利用シーン: 事前学習、OSCE/模擬試験、OJTの事例検討、評価面談

## 2. 必須機能・制約
- シナリオの選択・難易度設定
- 役割別対話（患者/家族/看護師/指導者）
- 逐次対話と行動選択の記録
- 記録作成支援（SOAP/経過記録）
- 評価スコアとフィードバック提示
- 監査ログと学習履歴の保管
- 制約: 医療上の最終判断は人が実施、個人情報保護・安全性ガイドライン遵守

## 3. シナリオ範囲と学習目標
- 訪問前準備: 情報収集、リスク予測、持参物の判断
- 訪問中対応: バイタル確認、観察/アセスメント、看護計画の提案
- 記録: 重要事項の記載、SOAP整合性
- 家族対応: 説明、同意、セルフケア支援
- 緊急時: 悪化兆候の判断、エスカレーション、救急連携

## 4. 役割設計・対話フロー・評価ルーブリック
- 役割: 患者、家族、看護師（受講者）、指導者（評価/解説）
- 対話フロー: 事前ブリーフ → 訪問シミュレーション → 記録作成 → デブリーフ
- 評価観点（各1-4点）: 情報収集、臨床判断、安全配慮、コミュニケーション、記録品質

## 5. 必要データ・ライセンス・匿名化
- データ: 事例集、訪問看護ガイドライン、手順書、教育教材
- ライセンス: 出典/利用条件を台帳化して確認
- 匿名化: 実名/住所/施設名の除去、合成データ化、最小限の保持

## 6. システム構成
- フロント: 学習UI、シナリオ選択、記録作成、結果表示
- API: 認証、セッション管理、シナリオ配信
- LLMオーケストレーション: 役割制御、ルール適用、回答検証
- シナリオ管理: バージョン管理、難易度、学習目標
- 評価/ログ: スコアリング、フィードバック生成、監査

## 7. 安全対策・品質基準
- 誤情報抑制: 重要事項は出典提示/確認質問を促す
- エスカレーション: 危険兆候や禁忌は即時指導者へ
- 禁則: 投薬/診断の断定、個人情報の要求
- 品質基準: 事実一致性、安全性、共感性、説明の明瞭さ

## 8. MVP範囲
- 最小シナリオセット（例）: 服薬管理、褥瘡予防、急変対応の3ケース
- 必須機能: 役割対話、シナリオ進行、記録支援、評価・デブリーフ

## 9. 有効性評価・運用計画
- 有効性評価: 事前/事後テスト、OSCEスコア、満足度アンケート
- 運用: 定期レビュー、ガイドライン更新反映、指導者向け管理画面

## 10. 追加開発ロードマップ
- Phase 1: MVP提供、学習ログの可視化
- Phase 2: シナリオ拡充、多言語、音声対話
- Phase 3: 電子記録連携、分析ダッシュボード、教育機関向け運用機能
